# Modern PHP & Tailwind CSS Job Portal

A modern, responsive career platform built with vanilla PHP, PDO MySQL, and Tailwind CSS.

## Features
- **Modern Typography & Tokens**: Inter / Plus Jakarta Sans pairing with slate and brand-violet palettes.
- **Hero & Visual Discovery**: High-converting search banner with active keyword and category pills.
- **Responsive Job Card Components**: Dynamic avatar fallbacks, salary tags, and employment badges.
- **Sticky Faceted Sidebar**: Real-time category counters, full-text search, and job-type filtering.
- **Pagination & Empty States**: Clean query preservation pagination with dashed feedback containers.
- **Application Flow**: Single-page job reviews with slide/blur modal application submissions.
- **Dashboards**: Candidate tracking portal, Employer listings manager, and profile settings.
